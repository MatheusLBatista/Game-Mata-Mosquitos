# 🦟 Game Mata Mosquitos

Bem-vindo ao **Game Mata Mosquitos**, um jogo simples e divertido onde os jogadores testam seus reflexos eliminando mosquitos que aparecem aleatoriamente na tela!

## 🎮 Sobre o Jogo

Este projeto foi criado com o objetivo de entreter e desafiar os jogadores enquanto desenvolvem suas habilidades de agilidade. O mosquito aparece em posições e tamanhos aleatórios, e o jogador precisa ser rápido para clicar e eliminá-lo antes que ele desapareça.

## 🛠️ Tecnologias Utilizadas

- **HTML** – Estrutura do jogo  
- **CSS** – Estilização da interface  
- **JavaScript** – Lógica e interatividade

## 🚀 Como Jogar

1. Acesse a [página do jogo](https://matheuslbatista.github.io/Game-Mata-Mosquitos/main.html).
2. Escolha o nível de dificuldade.
3. Clique nos mosquitos o mais rápido possível para ganhar pontos.
4. Evite deixar os mosquitos escaparem — você tem um número limitado de vidas!
